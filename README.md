 CodeVault

A lightweight developer productivity tool for storing, organizing, searching, and managing reusable code snippets in one place.

CodeVault helps developers avoid repeatedly searching for commonly used code by providing a simple personal snippet library directly in the browser.

 ✨ Features

- Add, edit and delete code snippets
- Search and filter saved snippets
- Mark important snippets as favorites
- Syntax highlighting for better readability
- Dark mode support
- Import and export snippets using JSON
- LocalStorage-based persistence
- Snippet and favorite counters
- Responsive and simple interface

 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Prism.js
- Browser LocalStorage

 🎯 Why CodeVault?

Developers frequently reuse small pieces of code across projects. CodeVault provides a simple way to build and maintain a personal reusable code library without requiring an account or backend server.
